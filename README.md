# 💗 yourGirlFriend · 铝盆友

> **11 年前，大妈在这个仓库留下一句话："这个可以有…对应的铝朋友版本也请同步开发！替诸君先谢谢了！"**
> **2026 年，AI 时代到了。铝盆友，回来。**

2015 年，YourBoyfriend 的评论区里冒出这句话，于是这个仓库出生了——没有它，就没有"铝盆友"这条产线。

十一年里，你们在这里许了 130+ 条愿望：卖萌鼓励、聊天谈心、陪聊电影书、催 ddl、暖床、会讲黄段子、"接得住我扔的段子"。最高赞的一条是："偶尔男女朋友的用户能即时交流一下就无敌了"；最清醒的一条是："不要太粘人——给彼此适当的空间"（issue #23）。

当年不是不想做，是真的做不到：语音像机器人、没有人格、没有记忆、没有形象、没有暖床的硬件——一行代码撑不起一个"她"。

2026 年，墙塌了。大模型、情感计算、语音克隆、数字人、IoT、暖床的硬件全都有了 API——**当年接不住愿望的技术，现在全都在。我们和蓝盆友一起回来重启。**

双子项目，来自 [💙 YourBoyfriend（蓝盆友）](https://github.com/YixuanFranco/YourBoyfriend)。同一个引擎，两条产线——**但铝盆友有自己的方向，不是谁的附庸。**

## 🔭 我们在调研什么（截至 2026-10）

重启不急着写代码——先把十一年的愿望吃透，再决定做什么。当前在跑这些方向：

1. **需求真相**：把 114 条许愿逐条判读——卖萌 / 温柔 / 体贴是高频真需求，"不要太粘人"是边界感需求，暖床 / 拥抱指向硬件层，配队交流是全场最高赞
2. **人类可量化评价体系**：身体 / 思维 / 环境 / 命理 四域 × 40+ 维度雷达 + Survey 问卷——填自己 → 出雷达 → 匹配适合你的 AI 伴侣（或真人）
3. **双模式**：许愿模式（YY / 身心灵，给你做梦的）vs 现充模式（实打实找对象，给你落地的）——两个都要
4. **地域环境坐标基准**：不同地域的人在一起，会遇到什么惊喜、什么困难（口味、气候、习惯——带环境成因，不贴标签）
5. **感知 → 具身闭环**：从"会聊天"到"会疼你"——记忆、主动关怀、暖床 IoT 硬件
6. **合规分级**：《人工智能拟人化互动服务管理暂行办法》已施行，G / PG-13 / R 三档闸门是引擎字段，不是事后补

**调研是持续进行的。** 每完成一轮，结论更新到 [wiki](https://github.com/YixuanFranco/yourGirlFriend/wiki) 和本 README；也欢迎你在 [issue #1](https://github.com/YixuanFranco/yourGirlFriend/issues/1) 点名下一个方向。

## 🎴 核心玩法：角色卡引擎（女友版）

与蓝盆友共用同一套 L1–L7 决策树引擎，关系方向选"女友"即可：

```
L1 关系方向   → 女友
L2 地域出身   → 34 省级（身高 / 方言 / 地域梗 / 饮食 / 节日）
L3 人格类型   → 8 款女友：姐姐款 / 妹妹款 / 妈妈款 / 爸爸款 / 炫耀款 / 示威款 / 游戏对手款 / 卖萌款
L4 声线       → 类型 × 地域 推荐组合（方言口音 = 记忆点）
L5 技能包     → 关怀 / 任务 / 娱乐（卖萌鼓励、多喝热水、催 ddl、陪写代码、翻译、唱歌……）
L6 关系阶段   → 暧昧 / 热恋 / 稳定 / 老夫老妻
L7 内容分级   → PG-13（默认）/ R（海外成人档，合规闸门）

输出：可运行的伴侣角色卡（JSON schema），与蓝盆友互通
```

- "姐姐款 / 妹妹款 / 妈妈款 / 爸爸款…向哥们炫耀款 / 向前女友示威款 / 游戏对手款"——这句 2016 年评论区原话就是今天的卡池设计。
- 组合爆炸：34 省 × 8 款 × N 声线 × M 技能 = **千级角色池**，天然适合投票、分享、二创。
- **第一期能玩什么**：输入省份 + 身高 + 性格标签 → 生成 5 字段角色卡 → 微调 → 导出分享。

## 🏗️ 双轨制：开源内核 + 商业外壳

与蓝盆友同一条路，共用同一个引擎：

| 轨道 | 内容 | 谁在用 |
|:---|:---|:---|
| **开源内核** | 角色卡解析引擎、对话编排、人设系统；个人可本地跑 | 开发者、玩家、二创社区 |
| **商业外壳** | 托管服务、角色卡市场（创作者分成）、企业定制 | 不想折腾部署的用户、IP 方 |

- 开源内核用 **AGPL-3.0 + 商业双许可**：社区永远免费，企业商用买例外许可。
- 角色卡市场：创作者定价卖卡、平台抽成（70/30）——创作者拿大头。
