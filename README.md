# 💗 yourGirlFriend · 铝盆友

> **隔壁那个睡了十一年的蓝盆友都醒了，铝盆友当然同步上线。**

2015 年，一条评论在这个仓库留下第一句："这个可以有…对应的铝朋友版本也请同步开发！替诸君先谢谢了！"——于是有了它。

十一年里，这里攒下 130+ 条愿望：卖萌鼓励、聊天谈心、催 ddl、暖床、会讲黄段子、"接得住我扔的段子"。最高赞的一条是："偶尔男女朋友的用户能即时交流一下就无敌了"。

2026 年，AI 时代到了。**我们和蓝盆友一起回来重启。**

双子项目，来自 [💙 YourBoyfriend（蓝盆友）](https://github.com/YixuanFranco/YourBoyfriend)。同一个引擎，两条产线。

## 🔭 我们在调研什么（与蓝盆友同一套引擎，截至 2026-10）

1. **需求真相**：114 条许愿判读——卖萌温柔是高频，暖床拥抱是硬件层，配队交流是最高赞
2. **人类可量化评价体系**：身体 / 思维 / 环境 / 命理 四域雷达 + Survey 问卷匹配
3. **双模式**：许愿（YY / 身心灵）vs 现充（真实择偶落地）
4. **地域环境坐标基准**：跨地域结合的惊喜与困难
5. **感知 → 具身闭环**：记忆、关怀、IoT 硬件
6. **合规分级**：G / PG-13 / R 三档闸门（与蓝盆友一致）

**调研持续进行，每轮结论更新到 [wiki](https://github.com/YixuanFranco/yourGirlFriend/wiki) 与本 README。**
